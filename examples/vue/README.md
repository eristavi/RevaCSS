# Vue reference application

Install the two local tarballs described in the
[adapter guide](https://github.com/eristavi/RevaCSS/tree/main/integrations/vue),
then run `npm install` and `npm run dev` here. The app uses Vue 3.5, the normal Vite
Vue plugin, and the existing RevaCSS stylesheet. Its form demonstrates initial
models and validation markup; it has no submission endpoint and the send button is
disabled. Core CSS remains independent of Vue. The three-engine browser fixtures passed; see the release record for model, native-control, reflow and accessibility-check scope.

Release scope and evidence: [2.0.0 validation record](https://github.com/eristavi/RevaCSS/blob/main/quality/releases/v2.0.0.md).
