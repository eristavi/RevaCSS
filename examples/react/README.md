# React reference application

Install the two local tarballs described in the
[adapter guide](https://github.com/eristavi/RevaCSS/tree/main/integrations/react),
then run npm install and npm run dev here. This React 19/Vite app shows a controlled
input, a DOM ref, native initial select values and validation markup. The form has
no endpoint; submission is prevented and its send button is disabled. Interaction
and browser acceptance remain deferred until the 2.0 release review.
