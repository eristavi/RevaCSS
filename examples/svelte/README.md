# Plain Svelte reference

Install the local core/adapter tarballs described in the
[adapter guide](https://github.com/eristavi/RevaCSS/tree/main/integrations/svelte),
then npm install and npm run dev here. Uses Svelte 5 runes/snippets, value bindings
and an explicit DOM element binding. The demo form prevents submission and has
no endpoint. Browser/model/ref interaction acceptance is deferred until 2.0 review.
