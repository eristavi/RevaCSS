# AI guidance evaluation — 16 October 2026

## Scope and method

Documentation baseline: `d1861e9b82b5cac6eb70e92b3448ff406761a5f4`, after
the first nine documentation improvements. Core reference: RevaCSS 2.0.0.
Evaluator runtime: Python 3.12.14.

Codex generated one batch of five complete native-HTML pages in this
conversation after reading the AI references. Prompts and expected contracts
were recorded alongside the outputs. The evaluated fixtures required no markup
repairs. This is an in-session, documentation-conditioned batch; the same
assistant authored the guidance and evaluation. It is not a blind trial,
independent review or comparison of model providers.

The evaluation checked static markup and file dependencies, with deliberate
negative variants to test the validator. It did not run browser rendering,
native activation, screen-reader/device review, adapter compilation/hydration or
form submission for these fixtures. Full Astro site build remains unverified in
this local environment because its Astro dependency is unavailable.

## Results

| Generated scenario | Principal contract checked | Result |
| --- | --- | --- |
| Landing page | Shared theme/accent/shape, native action link, card structures and details/summary FAQ | Pass |
| Scoped Glass cards | Scoped core/extension, .reva boundary, host content outside it and local Solid reset | Pass |
| Dashboard | Separate responsive wrapper, native metric markup and labelled scrollable table | Pass |
| Responsive navigation | Complete native top-menu structure, unique mobile panel ID and matching open/close controls | Pass |
| Server-returned form error state | Known action/method, labels/names, native constraints, escaped value and linked error descriptions | Pass |

**Five of five recorded fixtures passed the implemented static checks.** This
is a result for these files and checks, not an estimated success rate for future
AI responses or a claim that every property in the prompts has been measured.

**Fourteen of fourteen negative controls were detected:** unsupported value,
foreign framework class, missing material extension, missing scoped boundary,
containment on a card, duplicate ID, broken popover target, missing label,
incorrect button appearance attribute, extension order, missing material
selection, broken error description, missing required constraint and malformed
metric structure.

The machine-readable
[result record](https://github.com/eristavi/RevaCSS/blob/main/quality/ai-guidance/results-2026-10-16.json)
contains fixture SHA-256 hashes, individual diagnostics, the documentation
revision and stated limits. A detection can include additional diagnostics;
the required diagnostic must be present for its negative control to pass.

## What this establishes

The recorded guide context was sufficient to produce these five fixtures
without the selected API/structure mistakes. The validator also rejected the
fourteen deliberately introduced mistakes. It provides a reproducible starting
point for checking future documentation or output changes.

No new ambiguous guide instruction was identified by these static scenarios.
The evaluation exposed areas where a shallow validator could incorrectly count
tag presence as sufficient: material selection/order, metric parent structure
and native required constraints. Those checks were strengthened before the
final run; the original generated HTML files were preserved.

## What remains unmeasured

- Fresh outputs from other independent model sessions/providers and their
  first-pass/repair rates.
- Actual responsive reflow, material paint, inheritance/contrast preferences,
  focus, keyboard and native popover behaviour in supported browsers/devices.
- Framework-specific generated code compilation, server/client boundaries and
  hydrated bindings beyond existing adapter reference evidence.
- End-to-end routes, CSRF, authorization and saved state for new generated
  applications. The earlier runnable example's HTTP checks have their own scope.
- Full rendered-site/link validation for these documentation additions in this
  local environment.

A static result does not establish accessibility conformance or a universal
10/10 quality certification. The guide now has explicit usage rules, examples,
diagnostics, contributor instructions and a measured baseline; future evidence
should extend that baseline without replacing its history.

## Repeat or extend

From a source checkout with matching compiled CSS and Python 3.10+:

```sh
npm run test:ai-guidance
python3 tests/ai/evaluate.py --json
```

These commands recheck the recorded files; they do not call a model or generate
fresh responses. Read the
[evaluation instructions](https://github.com/eristavi/RevaCSS/blob/main/tests/ai/README.md)
before adding another batch. Preserve prompts, original outputs, model/context,
documentation revision and any failures before repair. Revisit the source guide
when an observed failure reveals a documentation gap.
