# Erisian 1.0.0 validation

Release date: 4 October 2026 (Asia/Nicosia).

Scope: public GitHub release with downloadable assets. npm remains private.

## Automated verification

Verified with Node 24.19.0 and Playwright 1.63.0 in the Linux cloud environment.

| Check | Result |

| CSS and documentation build | Passed; 383 pages generated |
| Unit suite | 55 passed; no failures or skipped tests |
| Chromium 153.0.8010.12 | 316 browser cases passed |
| Firefox 155.0 | 316 browser cases passed |
| WebKit 26.6 | 316 browser cases passed, including targeted timeout reruns |
| Distribution archives | 99 files each; ZIP integrity, ZIP/tar byte parity, safe paths, licenses, version metadata, and checksums verified |
| Reproducibility | Two packaging runs produced identical SHA-256 manifests |
| Extracted starter | Passed in all three engines at 375px with JavaScript disabled, keyboard disclosure, no page overflow, and no failed requests |
| Core size | 91,904 bytes minified; 14,420 bytes gzip with Node's default settings, below the 15 KiB budget |
| Design preservation | All 44 compiled CSS files are byte-for-byte identical to the reviewed pre-release build |

The full run executed 948 cases: 939 passed and nine WebKit cases exceeded the default cloud rendering time budgets. An isolated rerun with one worker, `LP_NUM_THREADS=1`, and a 90-second test timeout passed eight of those nine. The response-control fixture opens ten animated panels and had its own 60-second limit; increasing its allowance to 120 seconds let it complete in approximately 72 seconds. That final case passed separately. Every unique browser case passed; no test or interaction assertion was skipped, and native motion remained enabled.

Browser libraries were installed from verified package metadata and checksums into the workspace. `PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1` was used after direct library-load and browser-startup verification because the system library inventory does not discover the locally installed GLES library. Firefox used `MOZ_DISABLE_CONTENT_SANDBOX=1` for this container. These are headless browser results, not physical Safari/iOS or screen-reader acceptance.

To reproduce the downloads after building, run `npm run release:package`. The generated `artifacts/` directory contains the ZIP, tar.gz, standalone minified core, and `SHA256SUMS.txt`.

## Test contract corrections

- Glass paint is checked at the accepted 32% backing and 12px blur. The native blur comparison includes the current sheen and theme surface.
- Glass surface contrast calculations use theme-matched backdrops at 32%, replacing the obsolete 70% model. Action contrast retains the black/white backdrop checks at its current 90% backing. Arbitrary image/backdrop contrast is not certified by these checks.
- Semantic secondary/success expectations follow the existing adaptive role manifest; all six explicit primary accents are still exercised.
- Documentation may contain only its approved optional settings scripts. Native operation remains tested with JavaScript disabled.
- The scrolling navbar-inheritance code sample follows the existing named, focusable-region pattern and has keyboard regression coverage.
- The response-control test allows software-rendered WebKit additional time to open ten animated panels; its interaction, disabled-state, geometry, and native-motion assertions are preserved.
