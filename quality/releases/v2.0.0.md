# RevaCSS 2.0.0 release candidate

Status: readiness coverage completed on 14 October 2026; additional font selection is undergoing validation. Production publication remains blocked on fresh manual acceptance. This record does not certify physical-device or assistive-technology acceptance.

## Scope and compatibility

Default and Mono remain built in; removal of twelve previously shipped palette values is a breaking change. Follow [the migration guide](../../MIGRATION.md). Custom shape, density and page width, responsive/RTL refinements, native-input fixes and documentation accordion corrections are included. Veil remains available but deprecated. Core CSS remains independent of the optional documentation customizer and decorative demo backgrounds. Published 1.2.1 archives remain unchanged.

The readiness corrections fix the optional customizer discarding an explicit Default palette, obsolete documentation script/link expectations and version-specific release automation. Downloads include their linked guides, starter assets and package entry points, including stylesheet declarations. The framework core and its compiled CSS bytes are unchanged by this preparation PR.

## Build and package results

- CSS and documentation compilation passed: 231 generated pages. Both root-path and GitHub Pages project-path checks run in CI.
- Unit and documentation-link checks: 38 passed, zero failed. Actual offline tarball consumers: five passed, covering included Markdown links, distribution bytes, exports, Vite and strict TypeScript imports.
- Dependency audit: zero vulnerabilities.
- Core: 106,135 minified bytes; 16,002 bytes with Node's default gzip, below the 17,408-byte budget. Optional modules and fonts remain separate.
- ZIP and tar.gz archives contain identical files. Every `main`, `style`, `types`, `unpkg` and `jsdelivr` entry resolves; included Markdown links resolve; starter and index HTML match. Two independent builds produce identical SHA256SUMS. No framework JavaScript enters the distribution.
