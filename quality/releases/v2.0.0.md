# RevaCSS 2.0.0 release candidate

Status: preparation in progress. This record does not authorize publication or certify physical-device or assistive-technology acceptance.

## Scope and compatibility

Default and Mono remain built in; removal of twelve previously shipped palette values is a breaking change. Follow [the migration guide](../../MIGRATION.md). Custom shape, density and page width, responsive/RTL refinements, native-input fixes and documentation accordion corrections are included. Veil remains available but deprecated. Core CSS remains independent of the optional documentation customizer and decorative demo backgrounds.

## Validation

- Documentation and CSS compilation passed during preparation.
- Local unit and documentation-link checks pass: 38 checks. Installed-package verification passes: four checks covering actual offline tarball installation, export resolution, Vite asset handling and strict TypeScript imports.
- Chromium, Firefox and Linux WebKit regression checks run on the explicitly marked review branch, using the pinned Playwright dependency. Local browser downloads were unavailable in the execution environment.
- Actual Safari/iOS rendering, screen readers, zoom, text spacing, print and approved visual states require a fresh manual review for relevant changes. This is recorded as `Q-CANDIDATE-MANUAL-ACCEPTANCE` in the release-blocker registry. Historical 1.1.0/1.2.1 sign-offs do not establish acceptance of this candidate.
