### Optional Astro adapter

The separate `integrations/astro` package is an unpublished `2.0.0-dev.0`
candidate for Astro 7. Build/markup checks on Node 24.19.0 and locked Astro 7.3.5

screen-reader and visual acceptance for this adapter remain deferred; existing core
acceptance does not certify the new wrappers. No CSS, tokens, runtime dependencies
