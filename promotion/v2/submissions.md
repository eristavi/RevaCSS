## Show HN

Title: Show HN: RevaCSS – HTML-first CSS with shared appearance defaults

URL: https://eristavi.github.io/RevaCSS/launch/index.html

First comment:

I built RevaCSS to explore a fairly simple approach: write native HTML, set appearance defaults on a parent, and let the components share them through CSS.

The core has no JavaScript runtime and the compiled stylesheet needs no build step. Disclosures and popovers use native browser controls. Structural classes cover cards, grids, containers and similar layout patterns; data attributes choose themes, palettes, geometry and spacing.

The linked page contains three small HTML/CSS demos and lets you open each in CodePen. The full documentation also includes larger examples and separate framework integrations.

Version 2.0 is MIT-licensed and available on GitHub: https://github.com/eristavi/RevaCSS/releases/tag/v2.0.0

I am the maintainer. I would welcome feedback on whether parent-level appearance settings help keep a real interface consistent, and where that approach becomes awkward.
