Let the browser handle interaction

Open the disclosures, try the exclusive group, and open the popover. These controls use native HTML without JavaScript.

Questions, answered

Does this need JavaScript?

No. The browser handles opening and closing through details and summary. Matching name values make this group exclusive in supporting browsers.

Can I change the appearance?

Set data attributes on a parent, or use ordinary CSS custom properties for your own design tokens.

What about motion?

Supporting browsers enhance native disclosures with CSS motion. Other browsers keep usable native behaviour; reduced-motion preferences are respected.

A native popover

The opening button uses popovertarget. Try clicking outside the popover or pressing Escape to dismiss it.

HTML owns the behaviour

RevaCSS provides the appearance. The browser provides the popover.
